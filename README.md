# Copilot Agent Demo

A minimal Python project demonstrating a simple calculator CLI.

## Features
- `add`, `sub`, `mul`, `div` operations
- Division-by-zero check with a clear error message

## Usage

Run the calculator from the command line:

```
python main.py add 2 3
python main.py div 10 2
python main.py div 10 0  # shows error for divide by zero
```

No external dependencies; see `requirements.txt`.
